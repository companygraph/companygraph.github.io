The mapping

A generator reads it both ways: from a tool’s export into pages, and from pages back into the exchange format.

  • Application Component, Node, System Software, Device, Equipment, Communication Networka system, whose kind’s element names which one it is
  • Application Interface, Technology Interfacethe As of a Connects to row
  • Data Objecta data-object, realizing its business object, a core concept
  • Access, with its modea Holds row: writes or reads, the leading writer master
  • Function, Artifactdropped: internal behavior nobody can name a user of

Where it departs

Where the pack does not do what ArchiMate or LeanIX do, its README says so and says why.

rests onconcept Pack
  • Six elementsone type, the kind’s element naming which one, so the element comes back exact
  • An interfacea row, not an element; its name survives in As
  • Triggeringcomes back as Flow: a row says what is carried and how, not whether it starts something
  • Functions and artifactsno page, by core’s rule that a thing nobody can name a user of is not a feature
  • Accessreadwrite is writes, since a writer reads, and master is a claim ArchiMate does not make
  • LifecycleLeanIX’s phase-in and active are one active: the model says what is, not when it will be
