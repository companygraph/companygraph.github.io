How to read it

A folder is the plural of its type. What sits in a folder is one page of that folder's type — nothing is abbreviated, because the one rule that makes both names predictable cannot afford an exception.

A page is a file when it owns nothing, and a folder when it owns collections of its own. The profile is the example of the second: it holds its own file and, beside it, the experiences that belong to it.

Every line is a name written in a file. Nothing here is a link that can break: a name that points at nothing is an error, not a warning.
