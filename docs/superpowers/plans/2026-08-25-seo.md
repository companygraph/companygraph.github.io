# SEO — plan

*Spec: `docs/superpowers/specs/2026-08-25-seo-design.md`.*

## 1. The checks, first

Port `seo` from `blust.ch`'s suite; set `seo: true` on all six pages. Add the crawl-map
block this suite never had. Run it, and confirm it fails on the landing page as `main`
carries it — six missing tags named individually. Re-run after the fix to confirm it
passes for the right reason, not because the assertion is vacuous.

## 2. The landing page's head, put back

Canonical, description, `og:site_name`, `og:image:alt`, `og:locale`,
`og:locale:alternate` — in the order the other five pages carry them, so the six heads read
the same way. `/talks/` gets the three it is missing.

## 3. Structured data, rebuilt so it resolves

Every page carries `Organization`, `WebSite`, its own `WebPage` and — where nested — a
`BreadcrumbList`. The landing page adds `SoftwareSourceCode` with the repository and the
Apache-2.0 licence, both read off the GitHub API rather than copied from the prose.

## 4. Re-render the cards

Every page's markup moved, so every card is stale by the recipe's design. `npm run og`,
and commit `og.png` and `og.sha` together.

## 5. Verify

`npm run test:og`, `npm run og:check`, `npm run test:example`, `npm run example:check`,
then the browser suite against a served copy.
