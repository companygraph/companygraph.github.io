# The talk on core and packs — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The first of the four talks the spec sets out, "One core, and the words your company adds", at `/talks/core-and-packs/`, in English and German, narrated, with both PDFs, its card and its place on `/talks/`, the README and the sitemap.

**Architecture:** A deck is one hand-written `index.html` under `talks/<slug>/`, built from the what-stays talk's page as its shell, plus a `scenes.js` that animates its windows and a `tts/generate.py` copied unchanged. A talk is registered in six places: `talks/index.html`, `verify/check.mjs`, `build/jsonld.mjs`, `export-pdf.mjs`, `og-recipe.mjs` and `sitemap.xml`, and its narration in `.github/workflows/ci.yml` and `pins.json`. The work lands in the commits the what-stays talk landed in — 3de22e6, 4c5222f, c8106dc and 0dbcf52 — each under its seat, after one re-pin.

**Tech Stack:** HTML and CSS in the site's deck design, `deck.js` and `deck.css` from `@robertblust/design` v0.146.0, plain JavaScript for the scenes, Python 3 and the ElevenLabs API for the clips, Playwright for the PDFs and the card, Node 22.

**Spec:** `docs/superpowers/specs/2026-10-10-talks-on-core-and-packs-design.md`, sections 3 and 7.

## Global Constraints

- The worktree is `~/git/companygraph/companygraph.github.io-talks-on-core-and-packs`, on the branch `talks-on-core-and-packs`. Every command below runs there.
- Commits are authored by their seat at `companygraph.io`, `git commit --author "<Seat> <seat@companygraph.io>"`, with the trailers `Process`, `Phase`, `Track` and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, in the git register of `conventions/WRITING.md`, ending the body with a `Verified:` line. An agent commits when the owner has asked for the work; it never merges.
- English is en-US, with curly quotes, the spaced em-dash and no serial comma. German is de-CH, with ss, guillemets and the spaced en-dash, and is made only after the owner has reviewed the English.
- No number that still moves on a slide or in a note: no count of types, packs, pages or releases, and no version.
- Every slide names the pages of companygraph/mental-model it rests on, and every chip opens `../../?stage=expanded#<id>`, an id in `company.json` at the pinned commit.
- The rests-on chips and the tooling's output in a window stay English in both languages, as in the other talks.
- A slide claims only what the model or a run shows. Slide 4's claim was run on 2026-10-10 and holds (Task 2 runs it again).
- `export-pdf.mjs` re-renders every deck; the other decks' PDFs are put back as they were before committing (`git checkout -- talks/intro talks/obsidian-plugin talks/levels talks/what-stays` for the PDFs only).
- `ELEVENLABS_API_KEY` comes from the owner's shell profile, `~/.zshrc`, and is never printed.
